About

I turn ideas into reliable software.

A software developer with over three years of experiences, specializing in building scalable and secure enterprise systems using Java, Kotlin, and Salesforce. The journey began as a university student in 2019 then joining in forth semester as lecture assistant and instructor at Universitas Teknokrat Indonesia. Graduated in 2023 with GPA 3.7/4.0, followed by an apprenticeship at CODE ID as a backend developer contributing to an insurance platform built with Spring Boot and Quarkus, an experience that strengthened technical foundations in code structure, algorithmic thinking, and full-stack collaboration.

Currently serving as a Software Developer at AXA Mandiri Financial Services, with several high-impact backend initiatives delivered in support of digital transformation. A microservices-based migration of customer reporting from RPA to REST services was led, utilizing Apache Kafka and asynchronous Salesforce integrations, reducing annual licensing costs by 99.5% (from IDR 2 billion to IDR 10 million) while improving processing efficiency by 70%. Additional contributions include automation systems for internal policy and tax document processes with measurable annual savings, Salesforce reporting and call-handling enhancements that significantly reduced agent workload, remediation of Log4j vulnerabilities alongside the security team, and modernization of legacy SOAP-based systems into RESTful APIs.

Core technical expertise spans backend service development using Spring Boot and Quarkus across several microservices projects, Kotlin for Android-based mobile development, and proficiency in databases including MySQL, PostgreSQL, MSSQL, and MongoDB. Experience extends to secure API development, JWT authentication, API Gateway/Service Discovery, Docker-based cloud deployment, Apache Kafka streaming, and Salesforce CRM development using Apex, Visualforce and Lightning Web Components, complemented by open-source contributions on GitHub and knowledge shared through published articles on Medium. In addition also active as a mentor for the Islamic student association (Rohis) at SMAN 43 Jakarta.
